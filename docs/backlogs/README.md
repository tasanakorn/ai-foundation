# Backlogs

Ideas and requests that are not scheduled yet.

## 1. File names

1. Pattern: `backlog-<nnnn>-<slug>.<ext>` (for example `backlog-0001-example-slug.md`).
2. `<nnnn>` is the next free 4-digit number in this folder. Never reuse a number.
3. `<slug>` is lowercase kebab-case, 2–6 words.

## 2. Suggested header

```markdown
# backlog-<nnnn>: <Title>

- Status: open | accepted | rejected
- Source: <who / where it came from>
- Promoted to: <link to spec or task, once accepted>
```
