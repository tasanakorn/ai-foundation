# Products

Product-level docs: what each product is, who it is for, and its goals.

## 1. File names

1. Pattern: `<slug>.<ext>` — no kind, no number (for example `ai-gateway.md`).
2. `<slug>` is lowercase kebab-case, 2–6 words.
3. One file per product. Split into a sub-folder `<slug>/` only when one file gets too long.

## 2. Index

Add an `INDEX.md` here when the number of products makes a listing useful.
